# Latest release + resizable player update

Copy all files in the update ZIP into the root of your existing website repository, replacing matching files. The hidden `.github` folder must also be included. Your music files do not need to be uploaded again.

Commit and push, then open the repository on GitHub. In Settings → Pages, choose **GitHub Actions** under Source. In Actions, select **Refresh latest release and publish**, then **Run workflow**. This publishes the site and starts checking the channels approximately every six hours. Scheduled runs can be delayed by GitHub, and inactive public repositories may have schedules disabled after 60 days. Check Actions if updates stop.

The updater checks the peacepipe04 YouTube channel, Fetch Quest YouTube Music, SoundCloud, and Spotify releases. New Spotify releases must identify Fetch Quest in their metadata and link your exact artist profile. “No Reply” remains excluded. The checker compares dates rather than catalog order. Failed source checks keep the last successful release and are recorded in Actions logs and `release-sync-status.json` when a new release is saved. Public page formats can change; source failures appear in Actions. Fetch Quest's YouTube Music channel currently has no video list, so that source is reported as unavailable. This is a scheduled check, not an instant upload webhook. New featured releases are also added to the discography; their audio still needs a saved copy to survive deletion from streaming services.

The default is original tracks only. `release-settings.json` controls edits and excluded video IDs. Use `peacepipe04 - Track title` for new original YouTube uploads so artist ownership is clear. Put `Genre: ...` in the video description to supply the genre. The updater uses the artist's release notes for new-track copy; it does not invent listening analysis. Custom descriptions, genre, and mood can be supplied in the `notes` object, keyed by the YouTube video ID.

The spectrum uses Web Audio frequency data from whichever saved audio track is currently playing. YouTube, Spotify and SoundCloud embedded players do not expose their sound to the page; the bars stay still for these sources. To visualize the featured release, add its original audio file under `assets/audio/`, then set its `audio` path in `latest-release.json` and `latest-release.js`. Add the same path in `catalog.json` and `catalog.js` to keep it in the permanent archive. Genre and subjective feeling require listening to the audio; the updater will not generate pretend analysis.

Drag the player's bottom-right grip to resize it, or focus it and use the arrow keys (Shift makes smaller steps). Compact mode can also be moved with the top-left grip. The three existing layout buttons switch between horizontal, movable, and minimized views without restarting the song.
